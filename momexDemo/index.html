Momex

A personal finance app that collates data from multiple banks and investment platforms into one place. Bank and investment connections are pulled in through the Endute API alongside the Trading212 API, stored locally in an encrypted database, and visualised as balance and spending trends. Google Gemini generates AI reports on the database so you can ask questions about your finances in plain English.

// Features

  • Banks and investments combined in one overview
  • Transaction filtering and balance / spending trend charts
  • AI-powered database reports and search via Gemini
  • Biometric login
  • Encrypted local storage and encrypted backups
  • Weekly spending review reminders

// Tech Stack

  • Kotlin, Jetpack Compose & Material 3
  • MVVM + Repository architecture
  • Endute & Trading212 APIs via OkHttp
  • Google Gemini REST API
  • Room + SQLCipher (AES-256)
  • Vico charts & WorkManager
