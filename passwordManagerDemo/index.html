Password Manager

A secure password manager with a Kotlin mobile app and a Python desktop companion. Credentials for websites, apps and systems are stored in a locally encrypted SQLite database, and entries can launch the linked app or webpage directly. The vault can be exported to and imported from JSON with nothing sensitive left in plaintext, allowing the PyQt5 desktop app to view the same data on a PC.

// Features

  • Biometric login
  • Multiple users per device
  • Add, edit, copy and delete credentials (URL, username, password)
  • Open the linked app or webpage straight from an entry
  • Encrypted JSON import / export
  • Desktop viewer for the exported vault

// Tech Stack

  • Kotlin for the mobile app
  • Python for database management
  • SQLite database
  • Python cryptography library for encryption
  • JSON for data transfer
  • PyQt5 for the desktop app
