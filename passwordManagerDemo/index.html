Password Manager

Mobile and desktop apps written in Kotlin (front-end GUI) and python (database management / pc app) to allow a user to store and view passwords for websites / apps / systems. The database consists of a SQLite file which in the data is encrupted using the cryptography library. The database can be imported and exported to JSON file of which no notable information about the user or the passwords is in plaintext form. A destop app writin in PyQt5 allows the user to view the database via JSON file.

Features

  • Biometric login
  • Multiple users per device
  • Add, edit and delete password information
  • Information is displayed in triple: URL, username, password

Technologies Used

  • Kotlin for app development
  • Python for database management
  • Encryption / decryption for safe data storage
  • JSON for data transfer
  • PyQT5 for destop app
