Password Manager

A secure, offline password manager with an Android app built in Kotlin and Jetpack Compose, and a Python desktop companion. Every field in the vault is encrypted with AES-GCM using a key derived from the master password, and stored in a local SQLite database. Entries are organised into folders, can launch the linked app or website and hand the login over through Android's Autofill service, and the session signs out the moment the app is minimised. The vault can be exported to JSON with nothing sensitive left in plaintext, so the PyQt5 desktop app can open the same data on a PC.

// Features

  • Master password and biometric login, multiple users per device
  • Auto sign out when minimised or after 5 minutes idle
  • Folders, fuzzy search and collapsible password cards
  • Strong password generator
  • Open the linked app or website, with autofill of the login
  • Clipboard cleared 30 seconds after copying
  • Screenshots blocked and failed logins rate-limited
  • Encrypted JSON import / export
  • Desktop viewer with folders, search and copy

// Tech Stack

  • Kotlin + Jetpack Compose (Material 3) for the mobile app
  • Python embedded via Chaquopy for database and crypto logic
  • SQLite database
  • AES-GCM encryption with PBKDF2-HMAC-SHA256 key derivation
  • Android Keystore + BiometricPrompt for biometric unlock
  • Android Autofill service
  • JSON for data transfer
  • PyQt5 + PyInstaller for the desktop app
